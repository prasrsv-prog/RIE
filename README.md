## RIE Core v1 operator entry point

Gate 11 adds one installed `rie` console entry point with explicit
configuration, deterministic human or JSON results, stable exit codes,
append-only audit records, safe rerun behavior, and fail-closed recovery.

Operator documentation:

- `docs/operator/installation-and-configuration.md`
- `docs/operator/command-reference.md`
- `docs/operator/audit-and-recovery.md`
- `docs/operator/sample-workflow.md`

The controlled synthetic sample is under `samples/rie-core-v1/`.
Prompt Candidates are reviewable artifacts only; this software does not
execute prompts, invoke models, or generate creative output.
