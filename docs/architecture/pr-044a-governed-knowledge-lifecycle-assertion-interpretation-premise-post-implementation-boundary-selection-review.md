## 9. Candidate comparison

### 9.1 Interpretation-result contract before interpreter, transition, current state, repository, or persistence

This candidate creates a future architecture review for the minimum immutable non-authoritative result contract produced from one validated interpretation premise.

That future contract review would define representation only. It would not implement interpretation logic.

It can preserve contradiction visibility, explicit premise completeness, deterministic provenance, and separation from transition, current state, repository, and persistence.

Disposition: eligible and selected.

### 9.2 Direct interpreter implementation

This candidate would implement interpretation behavior before the output contract, status vocabulary, contradiction representation, sufficiency boundary, validation order, and authority exclusions are governed exactly.

Disposition: premature and not selected.

### 9.3 Current-state projection before interpretation result

This candidate would select current state or a current-effective assertion before a governed interpretation result exists.

That would collapse premise material into authority or state semantics without an approved contract.

Disposition: prohibited and not selected.

### 9.4 Repository or persistence before interpretation result

This candidate would add storage, query, admission, duplicate, idempotency, serialization, schema, or recovery behavior before the semantic result boundary is governed.

Storage cannot determine interpretation meaning or completeness.

Disposition: premature and not selected.

### 9.5 Transition execution before interpretation result

This candidate would treat assertions or premise material as proof that a lifecycle transition occurred.

No implemented premise field proves prior state, resulting state, transition authority, execution, or completion.

Disposition: prohibited and not selected.

### 9.6 None

`none` remains eligible if no safe next subject can be identified.

It is not selected because one architecture-only interpretation-result contract review can proceed without implementing behavior or weakening existing boundaries.

Disposition: eligible but not selected.
